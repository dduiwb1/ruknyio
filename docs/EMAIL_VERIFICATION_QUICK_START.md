# 🚀 دليل البدء السريع - مميزة التحقق من البريد الإلكتروني

## الخطوة 1️⃣: إنشاء نموذج بحقل بريد

1. اذهب إلى "إنشاء نموذج جديد"
2. أضف حقل من نوع **"البريد الإلكتروني"**
3. في نافذة تعديل الحقل، فعّل خيار **"التحقق من البريد"** (مع الدرع 🛡️)

## الخطوة 2️⃣: نشر النموذج

1. أكمل إعدادات النموذج الأخرى
2. اضغط **"نشر"** أو اجعل حالة النموذج **"مفعّل"**

## الخطوة 3️⃣: ملء النموذج من المستخدم

### القسم الأول:
```
┌──────────────────────────────────────┐
│ أدخل بريدك الإلكتروني              │
│ ┌──────────────────────────────────┐ │
│ │ name@example.com                 │ │
│ └──────────────────────────────────┘ │
│                                      │
│ [إرسال رمز التحقق]                  │
└──────────────────────────────────────┘
```

### القسم الثاني (بعد الضغط على الإرسال):
```
┌──────────────────────────────────────┐
│ ⏱️ الرمز ينتهي في 14:56             │
│                                      │
│ أدخل الرمز المكون من 6 أرقام       │
│ ┌──────────────────────────────────┐ │
│ │ 1  2  3  4  5  6                │ │
│ └──────────────────────────────────┘ │
│                                      │
│ [تأكيد]                             │
│                                      │
│ لم تستقبل الرمز؟ أعد الإرسال       │
└──────────────────────────────────────┘
```

### عند النجاح:
```
┌──────────────────────────────────────┐
│ ✅ تم التحقق من البريد بنجاح       │
│    name@example.com                  │
└──────────────────────────────────────┘
```

## 📊 سير العملية تقنياً

### من الـ Frontend:
```javascript
1. المستخدم يكتب بريده → يضغط "إرسال"
   ↓
2. Frontend يرسل: 
   POST /api/forms/public/my-form/send-verification-code
   {
     "fieldId": "field-123",
     "email": "user@example.com"
   }
   ↓
3. Backend يُنشئ رمز وينشره
   ↓
4. المستخدم يُدخل الرمز → يضغط "تأكيد"
   ↓
5. Frontend يرسل:
   POST /api/forms/public/my-form/verify-email-code
   {
     "email": "user@example.com",
     "code": "123456"
   }
   ↓
6. Backend يتحقق ويُرد النجاح
```

## ⚙️ الإعدادات والخيارات

### ما يمكن تخصيصه:
- ✅ **النص التوجيهي**: في حقل الوصف
- ✅ **Placeholder**: الكلمات المرشدة
- ✅ **Required**: جعل الحقل إجباري أم اختياري
- ✅ **التحقق**: تشغيل/إيقاف التحقق

### ما هو ثابت:
- 🔒 **الرمز**: 6 أرقام عشوائية آمنة
- ⏱️ **المدة**: 15 دقيقة
- 🔐 **المحاولات**: 3 محاولات فقط

## 🔐 معلومات الأمان

### ما الذي يتم تسجيله:
- 📍 عنوان IP للمستخدم
- 📱 معلومات المتصفح (User Agent)
- ⏰ توقيت الإرسال والتحقق
- 📊 عدد المحاولات

### ما الذي يُمسح:
- ❌ الرموز المنتهية الصلاحية (تلقائياً)
- ❌ بيانات المحاولات الفاشلة (بعد 24 ساعة اختياراً)
