# خطأ 535 Incorrect authentication data (QuickSign / البريد)

## ماذا يعني الخطأ؟

الخادم SMTP يرفض **بيانات الدخول** (اسم المستخدم أو كلمة المرور). النص الكامل غالباً:

```text
535 Incorrect authentication data
code: 'EAUTH'
command: 'AUTH PLAIN'
```

يظهر عند إرسال بريد QuickSign أو أي إشعار بريد من الـ API.

---

## ماذا تتحقق؟

### 1. متغيرات البيئة في `apps/api/.env`

يجب أن تكون مضبوطة بشكل صحيح:

| المتغير | الوصف | مثال (Gmail) |
|--------|--------|----------------|
| `MAIL_HOST` أو `SMTP_HOST` | عنوان خادم SMTP | `smtp.gmail.com` |
| `MAIL_USER` أو `SMTP_USER` | البريد الإلكتروني | `your@gmail.com` |
| `MAIL_PASSWORD` أو `SMTP_PASSWORD` أو `SMTP_PASS` | كلمة مرور التطبيق (App Password) | كلمة مرور تطبيق من 16 حرفاً |
| `MAIL_PORT` | المنفذ (اختياري) | `587` |
| `MAIL_SECURE` | TLS (اختياري) | `false` لـ 587 |

### 2. Gmail: استخدم App Password

- إذا كان الحساب Gmail مع **تفعيل التحقق بخطوتين** لا تستخدم كلمة مرور الحساب العادية.
- أنشئ **كلمة مرور تطبيق (App Password)**:
  1. حساب Google → الأمان → التحقق بخطوتين (مفعّل).
  2. كلمات مرور التطبيقات → إنشاء → انسخ كلمة الـ 16 حرفاً.
- ضع هذه الكلمة في `MAIL_PASSWORD` (أو `SMTP_PASSWORD` / `SMTP_PASS`) **بدون مسافات**.

### 3. مزودون آخرون (Outlook, Yahoo, شركات الاستضافة)

- **Outlook / Microsoft 365**: غالباً تحتاج App Password أو OAuth حسب الإعدادات.
- **استضافة (cPanel, Plesk, إلخ)**: استخدم بيانات SMTP التي يعطيك إياها لوحة التحكم (نفس البريد وكلمة المرور أو كلمة مرور البريد المخصصة).
- تأكد من المنفذ (مثلاً 587 لـ TLS، 465 لـ SSL) وعدم وجود مسافات زائدة في المستخدم أو كلمة المرور.

### 4. أخطاء شائعة

- مسافات في بداية أو نهاية البريد أو كلمة المرور في `.env`.
- استخدام كلمة مرور الحساب العادية مع Gmail مع تفعيل التحقق بخطوتين.
- اسم متغير خاطئ: الكود يقرأ `MAIL_PASSWORD` أو `SMTP_PASSWORD` أو `SMTP_PASS` (تمت إضافة دعم `SMTP_PASS`).

---

## بعد التعديل

1. احفظ `.env` بدون مسافات زائدة.
2. أعد تشغيل الـ API: `npm run dev:api`.
3. جرّب QuickSign (طلب رابط الدخول) مرة أخرى.

إذا استمر الخطأ، راجع إعدادات SMTP في لوحة مزود البريد أو وثائق Gmail/Outlook لـ "Less secure app access" أو "App passwords".
